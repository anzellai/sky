## Where we are

- **Branch:** `feat/v0.16.13-lowerctx-cascade` (1 commit ahead of `origin/main`:
  `docs: reinforce no-deferral principle`).
- **Compiler binary:** `sky-out/sky` is the clean `v0.16.11` baseline.
- **The bug:** Sky compiles `view : Cfg msg -> Element msg` to a generic Go
  function whose body emits `any(cfg).(Cfg_R[any])` instead of `[T1]`. Go's
  nominal generics make this panic at runtime under any concrete `msg`.
- **Live impact:** SkyDeploy's editor source-picker panics on
  `dev.skydeploy.app` (a live downstream Sky.Live app's editor).

## The fix (already named in the roadmap)

Documented in `docs/archive/improvement-plan-v0.16.md` §2 Priority 1:
**Thread `LC.LowerCtx` explicitly through `coerceCallArgsAt` and
`substituteOnly`** so the enclosing-TVar scope is a value-on-the-stack, not
a CAF-memoised IORef read. Sequence-equivalent / low-risk per the doc.
Estimated 14-16h splittable into 4-5 hour-sized commits.

## Dead ends already explored — DO NOT RE-TRY

| Approach | Outcome | Why |
|---|---|---|
| `forceAllChars` per-Char in `withScopedEnclosingTypeParams` | No effect on #530 | The leak isn't lazy chars; it's the CAF-cached IORef read. |
| New `_cg_enclosingTypeParams` field on `Rec.CodegenEnv` + per-call distinguisher reader | Closed #530 fixture but broke 58 Std.Ui specs | Polluted `getCgEnv`'s CAF; downstream readers got stale env from a DIFFERENT function's push. |
| Separate IORef + bang-pattern distinguisher reader | Same Std.Ui regression | Inner deps inherited outer deps' scope via UNION semantics. |
| REPLACE-not-UNION push semantics | Same regression | Outer `withScopedEnclosingTypeParams` re-unions. |
| Structural-slot-only preservation gate | Closed kernel-arm but broke user-defined sibling calls | Can't distinguish callee-T1-is-caller's vs callee-T1-is-local from string types alone. |
| Sky-source annotation workaround | Doesn't close panic on v0.16.11 | The bug is in σ-recovery / arg-coercion; annotation on view alone (or helpers alone) doesn't trigger the existing #521 fix. |
