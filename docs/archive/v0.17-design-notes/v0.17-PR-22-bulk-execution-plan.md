## 1. MappingContext extension

Today's record (`Type.hs:719`) already carries `mcRecordAliases`,
`mcUnionNames`, `mcEnumNames`, `mcAliases`, `mcTVarsToAny`. We ADD
six fields. None of them is consulted by existing callers under
`defaultMappingContext`, so PR-22a (the field add) is a no-op for
every current call site — same byte-identical-output contract as
PR-4.

```haskell
data MappingContext = MappingContext
    { mcRenderEnv         :: !RenderEnv
    , mcRecordAliases     :: !(Set.Set String)
    , mcUnionNames        :: !(Set.Set String)
    , mcEnumNames         :: !(Set.Set String)
    , mcAliases           :: !(Map.Map String Can.Alias)
    , mcTVarsToAny        :: !Bool

    -- PR-22 ADDITIONS
    , mcRuntimeTypedMap   :: ![(String, String)]
        -- Divergence #1.  Source: `Compile.runtimeTypedMap`
        -- (static; lifted as-is into the context).
    , mcQualRuntimeTyped  :: ![((String, String), String)]
        -- Divergence #2.  Source: `Compile.qualifiedRuntimeTypedMap`
        -- (static; needed to disambiguate Sky.Http.Server.Response
        -- vs Sky.Core.Http.Response).
    , mcRuntimeOnly       :: !(Set.Set String)
        -- Divergence #3.  Source: `Compile.runtimeOnlyTypes`
        -- (lifted to a Set for O(log n) membership).
    , mcAnonRecRegister   :: !(Map.Map String T.FieldType -> IO String)
        -- Divergence #8.  Callback-shaped IORef writer — pipeline
        -- pure code receives a registration function rather than
        -- the IORef itself.  `buildMappingContext` plugs in the
        -- real `synthAnonRecordName` writer; `defaultMappingContext`
        -- uses `\_ -> pure "Anon_R_unbound"` (test-only sentinel).
        -- See §3 for the IO-write pattern.
    , mcExtRecordPolicy   :: !ExtRecordPolicy
        -- Divergence #9.  ADT: AsAnyComment (today's default) |
        -- AsTypedFallback (use mcAliases lookup → registered shape).
    , mcFuel              :: !Int
        -- All divergences.  Mirrors legacy fuel cap (64 default;
        -- drops to "any" at 0).  Default = 64.
    , mcVisited           :: !(Set.Set String)
        -- All divergences.  Cycle guard.  Default = empty.
    }

data ExtRecordPolicy = AsAnyComment | AsTypedFallback
```

`buildMappingContext` adds three lines:

```haskell
buildMappingContext renderEnv cgEnv = MappingContext
    { ...                                          -- existing fields
    , mcRuntimeTypedMap  = runtimeTypedMap         -- imported from Compile
    , mcQualRuntimeTyped = qualifiedRuntimeTypedMap
    , mcRuntimeOnly      = Set.fromList runtimeOnlyTypes
    , mcAnonRecRegister  = synthAnonRecordNameIO   -- thin IO wrapper
    , mcExtRecordPolicy  = AsTypedFallback
    , mcFuel             = 64
    , mcVisited          = Set.empty
    }
```

This pulls `runtimeTypedMap` / `qualifiedRuntimeTypedMap` /
`runtimeOnlyTypes` into a new module `Sky.Generate.Go.RuntimeMaps`
to break the Compile↔Type.hs cycle (Type.hs cannot import
Compile.hs directly).

## 2. Pipeline arm changes (per divergence)

For each divergence, the change is to `mapSkyTypeToGo` /
`mapNamedType` / `mapRecordType` in `Type.hs`. Below uses
Haskell-style guards; all changes preserve the GoType ADT shape.

### Div #1 — `mcRuntimeTypedMap` (rt.SkyDecoder etc.)

In `mapNamedType`, BEFORE the user-defined fallback:

```haskell
| Just goTy <- lookup name (mcRuntimeTypedMap ctx)
, not isUserOverride
    -> GoBare goTy        -- emits rt.SkyDecoder, rt.SkyHandler, …
```

### Div #2 — `mcQualRuntimeTyped` (Sky.Http.Server.Response)

Checked BEFORE Div #1 (qualified wins over bare):

```haskell
| Just goTy <- lookup (modStr, name) (mcQualRuntimeTyped ctx)
    -> GoBare goTy
```

### Div #3 — `mcRuntimeOnly` (Route → any)

Last of the runtime-typed gates:

```haskell
| Set.member name (mcRuntimeOnly ctx)
    -> GoAny
```

### Div #6 — FFI hyphen mangle short-circuit

`splitGoMangledQualified name` is already in Compile.hs; lift to
`Sky.Generate.Go.RuntimeMaps`. Arm in `mapNamedType`:

```haskell
| Just _ <- splitGoMangledQualified name
    -> GoAny    -- before any user-ADT classification
```

### Div #7 — `mcUnionNames` snapshot timing

Already correct — `buildMappingContext` snapshots
`Rec._cg_unionNames` at call time, no IORef read happens in the
pipeline. The risk is callers that build the context BEFORE
`writeIORef globalUnionNames` runs in `lowerProgram`. **Mitigation:**
PR-22b adds a sanity assertion at every `buildMappingContext` site
in Compile.hs that `Rec._cg_unionNames cgEnv == globalUnionNames`
when the latter is non-empty (asserted via `Debug.Trace.traceM`
when `SKY_DEBUG_UNION_SNAPSHOT=1`).

### Div #8 — Anonymous record registration (the big one)

`mapRecordType` currently emits `GoStruct` inline. Legacy emits a
named `Anon_R_<hash>` AND registers the shape so a downstream
`type Anon_R_<hash> = struct{...}` declaration is emitted by
`lowerProgram`.

Refactor `mapRecordType` to a TWO-PATH function:

```haskell
-- pure path (current — used by tests + parity oracle)
mapRecordType ctx fields = GoStruct (mapFields ctx fields)

-- IO path (new — used by every production call site)
mapRecordTypeIO :: MappingContext -> Map String T.FieldType -> IO GoType
mapRecordTypeIO ctx fields = do
    -- (1) Alias-match check via mcRecordAliases / mcAliases —
    --     mirrors Compile.hs:17438 lookupRecordAlias.
    case lookupAliasByFieldSet ctx fields of
        Just (aliasName, argTys) ->
            pure (GoNamed (aliasName ++ "_R")
                          (map (mapSkyTypeToGo ctx) argTys))
        Nothing -> do
            -- (2) Synthesise + register Anon_R_<hash>.
            name <- mcAnonRecRegister ctx fields
            pure (GoNamed name [])
```

`mapSkyTypeToGoIO :: MappingContext -> T.Type -> IO GoType` is a
thin IO wrapper that delegates to `mapRecordTypeIO` at TRecord
arms and to `mapSkyTypeToGo` elsewhere. Every production migration
in §4 uses the IO variant; the parity test in `GoTypeAdtSpec`
keeps the pure variant.

### Div #9 — Extensible TRecord (`Just _`)

Today emits `GoRaw "any /* extensible record */"`. New arm:

```haskell
T.TRecord fields (Just _)
    | AsTypedFallback <- mcExtRecordPolicy ctx
    , Just aliasName <- lookupAliasByFieldSet ctx fields
        -> GoNamed (aliasName ++ "_R") []
    | otherwise -> GoRaw "any /* extensible record */"
```

The IO path uses `mapRecordTypeIO` which already covers this.

### Div #10 — TAlias chain recovery order

In `mapSkyTypeToGo`, replace the existing TAlias arms:

```haskell
T.TAlias home name typeArgs aliasTy
    -- (a) qualified-runtime first
    | Just goTy <- lookup (toStr home, name) (mcQualRuntimeTyped ctx)
        -> GoBare goTy
    -- (b) bare-runtime
    | Just goTy <- lookup name (mcRuntimeTypedMap ctx)
        -> GoBare goTy
    -- (c) record alias OR explicit recorded alias
    | isAliasInRegistry ctx name
        -> GoNamed (mkBase home name ++ "_R")
                   (map (mapSkyTypeToGo ctx . snd) typeArgs)
    -- (d) recurse into Hoisted/Filled body
    | T.Hoisted inner <- aliasTy -> mapSkyTypeToGo ctx inner
    | T.Filled  inner <- aliasTy -> mapSkyTypeToGo ctx inner
```

### Div #11 — TAlias-on-TRecord `_R` suffix

Subsumed by Div #10 step (c). The legacy `Hoisted/Filled (TRecord
_ _)` discriminator is replaced by the cleaner "is the name in
the alias registry" gate, which produces the same output AND
handles alias chains uniformly.

### Div #12 — TAlias `typeArgs` rendering

Step (c) of Div #10 already passes `typeArgs` through. The bug is
that today's pipeline recurses into `aliasTy` and forgets
`typeArgs`. Putting (c) BEFORE (d) is the fix.

### Div #13 — TTuple typed-vs-generic arity gate

`emitTupleTypeStr` + `isTypedTupleElementStr` are in Compile.hs.
Lift `isTypedTupleElement :: GoType -> Bool` to Type.hs (works on
the typed ADT directly — checks for `GoBare {prim}`, `GoNamed
"_R"-suffix`, `GoTuple {typed}` recursively). Then in
`mapSkyTypeToGo`:

```haskell
T.TTuple a b extras ->
    let elems = map (mapSkyTypeToGo ctx) (a : b : extras)
    in if all isTypedTupleElement elems
           then GoTuple elems            -- renders rt.T2[A,B]
           else GoNamed (tupleAlias (length elems)) []
```

`renderGoType` already handles both via the `renderTupleGeneric`
gate (today's policy switch already correctly picks per arity).

## 3. Anonymous-record IORef pattern

**Decision: callback in MappingContext, NOT a separate IO step.**

Rationale: every production caller already runs inside `IO` (they
read `globalCgEnv` / `globalUnionNames` via `readIORefNoCse`).
Adding a callback field keeps `mapSkyTypeToGo` pure (so the
parity test stays property-testable) AND lets the IO production
path register-on-demand without an explicit two-pass.

Two-surface API in `Type.hs`:

```haskell
-- Pure — used by RendererParitySpec + GoTypeAdtSpec.  Uses
-- defaultMappingContext whose mcAnonRecRegister returns a
-- sentinel name.  TRecord arms emit GoStruct inline as today.
mapSkyTypeToGo   :: MappingContext -> T.Type -> GoType

-- IO — used by every production caller.  Routes TRecord arms
-- through mcAnonRecRegister so the IORef write happens lazily
-- as the type tree is walked.
mapSkyTypeToGoIO :: MappingContext -> T.Type -> IO GoType
```

In Compile.hs, `synthAnonRecordNameIO :: Map String T.FieldType
-> IO String` already exists at `Compile.hs:18381` as
`synthAnonRecordName`. Wrap (it's already in IO via
`atomicModifyIORef'`).

Atomicity: `synthAnonRecordName` uses `atomicModifyIORef'`
already; concurrent `mapSkyTypeToGoIO` calls registering the
same field-set produce the same hashed name + a single registry
entry (the modify is idempotent on the value).

## 5. Verification strategy

**Before any slice:**
- Extend `RendererParitySpec` with one case per divergence —
  a hand-built `T.Type` + the expected Go string from both
  pipelines. Property: `solvedTypeToGoBounded 64 Set.empty t ==
  renderGoType defaultRenderEnv (mapSkyTypeToGo ctx t)` for
  every `t` in the corpus. Lock 13 cases (one per divergence) +
  the existing C2 oracle (~40 cases). Currently in
  `test/Sky/Build/GoTypeAdtSpec.hs`.

- Add a new `test/Sky/Build/PR22FixturesSpec.hs` per divergence
  — minimal Sky source that exercises ONLY that arm:
  - `Decoder String`-typed binding (Div #1).
  - `Sky.Http.Server.Response` vs `Sky.Core.Http.Response`
    typed handler (Div #2).
  - `Route`-typed binding that must collapse to `any` (Div #3).
  - FFI binding with mangled qualifier (Div #6).
  - 5-field anonymous record literal (Div #8).
  - `{ r | x = 1 }` row-poly use (Div #9).
  - Alias chain `type alias A = B; type alias B = …` (Div #10–12).
  - Tuple of typed records (Div #13).

**During each slice:**
- After S0–S5: run the focused fixture subset for the closed
  divergence. Should turn green.
- After every S6 subslice: full sweep + cabal must stay green.

**Bulk caller-migration safety (32 sites):**
- Add `SKY_RENDERER_DIFF=1` env. When set, every call to
  `mapSkyTypeToGoIO` ALSO calls `solvedTypeToGoBounded` and
  `Debug.Trace.traceM` on mismatch (with call-site file:line via
  TH `__LINE__`). Run the full sweep with this env set;
  zero traces = byte-identical migration. Stays in tree for one
  release as a regression net before S7 deletes the legacy
  functions.
