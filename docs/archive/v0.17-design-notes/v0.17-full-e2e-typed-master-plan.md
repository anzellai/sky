## What this plan delivers

By Ship Point B (~13 sessions in), Sky lowers heterogeneous
shapes to typed Go end-to-end:

```elm
-- Sky:    pair : (String, Int)
-- v0.17:  pair = rt.T2[string, int]{A: "hello", B: 42}
--         (was: rt.SkyTuple2{A: any, B: any})

-- Sky:    init _req = ({ count = 0 }, Cmd.none)
-- v0.17:  rt.T2[State_Model_R, rt.SkyCmd_T[State_Msg]]{...}
--         (was: rt.SkyTuple2{A: any, B: any})

-- Sky:    label : fyne.CanvasObject = widget.NewLabel "hi"
-- v0.17:  widget.NewLabel("hi")       // static assignment, HM-proven
--         (was: rt.Coerce[fyne.CanvasObject](widget.NewLabel("hi")))

-- Sky:    Cmd.batch [ Cmd.perform t1 M1, Cmd.perform t2 M2 ]
-- v0.17:  Std_Cmd_batch[State_Msg]([]rt.SkyCmd_T[State_Msg]{...})
--         (was: []any{...})
```

The `rt.AsInt`-class panics on heterogeneous-tuple destructure
close. Most FFI `rt.Coerce` calls become static assignments.

## The pre-mortem lessons (BAKED IN before PR-1)

A pre-mortem written by an adversarial agent ("assume the plan
failed; why?") predicted the exact failure: **PR-13
(`coerceCallArgsAt` σ structural) bisects to a TCO interaction
through `Sky.Build.TailCallOpt`**.

**Lesson 1 — at PR-1: probe corpus must include TCO probes**.
The audited ~50 canaries are all value-side type-misalignment
probes. None cover control-flow rewrites. Add `probe-TCO-1`
through `probe-TCO-7` covering:
* Tail-position polymorphic args (`let f x = f (g x)` shape)
* Mutual recursion through polymorphic callbacks
* `continue`-block coercion for typed tuple params
* `if` / `case` tail-position polymorphic-arg reassignment
* `let` tail-position polymorphic-arg
* Nested TCO through `Cmd.batch`-shaped HOF
* TCO across a Std.Ui callback boundary

**Lesson 2 — at PR-5: parity property must cover tail-position
regions.** When `Sky.Type.Solve.GoTypeBuild` ships, the property
test must include `tailPositionRegions :: Module -> [A.Region]`
from `TailCallOpt.hs`. Otherwise byte-identical parity is scoped
to expression-body regions only.

**Lesson 3 — at PR-8: defusing `scopeStateRef` changes timing
for `Sky.Build.TailCallOpt`'s `LowerCtx.enclosingTypeParams`
reads.** The IORef-defusing arc closes three IORefs but
introduces an ordering dependency. Pre-flight audit of EVERY
site that reads `_enclosingTypeParams` — including
`TailCallOpt.hs` (separate module).

**Lesson 4 — at PR-11: any 2-byte diff in a `continue` block is
a real bug, NOT a formatter quirk.** Do not classify and ignore.

These lessons are encoded as the durable feedback memory
`pre_mortem_v017_tco_lessons.md`.

   after 3 sessions of debug. → Seven-renderer divergence wider
   than audited.

   bisection finds > 5 unenumerated ambient-state call sites.
3. **PR-9 reveals Go's `types.Implements` is unreliable** for
   embedded interfaces at Stripe/Fyne scale (false-neg > 5%).
4. **PR-21 breaks principal types** — context-directed widening
   interacts pathologically with same-module polymorphic
   re-instantiation. Soundness regression.
5. **Two consecutive Phase γ PRs require force-push-revert.**
6. **Session count crosses 35** without reaching Ship Point B.

**On abort:** Phase α (PRs 1-8) STAYS. IORef defusing +
structural anon-record + threaded `LambdaScope` are durable wins
independent of Cause H. CLAUDE.md gets Limitation #11.
