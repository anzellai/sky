## Key architectural finding

The master plan's "1-1.5 sessions per IORef defuse" estimate assumed each IORef could be safely threaded individually. The wide-grep + architectural audit found:

* Only `globalCurrentDepModule`'s line 12417 fallback was a structurally safe single-PR defuse (and it shipped).
* `globalCurrentDepModule` line 7313 is a binary entry/dep gate baked into the sentinel architecture — needs LowerCtx threading.
* `globalAnonRecords` is a producer-consumer pattern across parallel renderer passes — needs renderer-state-threading.
* `scopeStateRef` is the master LowerCtx holder + deferred-thunk-loop avoidance pattern — most invasive, deepest reader/writer surface area.

All three deferred touchpoints share the same architectural fix: thread the relevant context as an explicit parameter through the renderer chain (Reader/State pattern). The right shape is **one consolidated PR** rather than three individual attempts.
