# Internationalisation: Std.I18n and Std.I18n.Format

`Std.I18n` gives an app locales, CLDR plural rules and translated messages.
`Std.I18n.Format` formats numbers, money, dates, times, lists and relative
time for a locale. The API is in `sky doc Std.I18n` and
`sky doc Std.I18n.Format`. This page tells how the parts fit together. The
example `examples/78-i18n-booking` shows a page in four locales.

## 1. Set up

List the locales in `sky.toml`, and put the messages in one folder per
locale:

```toml
[i18n]
locales = ["en-GB", "zh-Hans", "ar"]
default = "en-GB"          # every lookup chain ends here
catalogues = "i18n"        # optional; the default is "i18n"
```

```text
i18n/en-GB/booking.json
i18n/zh-Hans/booking.json
i18n/ar/booking.json
```

A catalogue file is a JSON object of key to message. A nested object makes
dotted keys, so these two files hold the same key `booking.title`:

```json
{ "booking": { "title": "Your booking" } }
{ "booking.title": "Your booking" }
```

An object whose keys are all plural categories (`zero`, `one`, `two`,
`few`, `many`, `other`) or exact numbers (`"=0"`) is a plural message. It
selects its form by the argument `count`:

```json
{ "booking.nights": { "=0": "No nights booked", "one": "{count} night", "other": "{count} nights" } }
```

A key the default locale has and another locale lacks falls back to the
default locale. A key in another locale must also be in the default locale.

## 2. What `sky check` checks

`sky check` and `sky build` check every catalogue before `go build` runs. A
problem fails the build with a code and a location. The codes are in
[errors/i18n-catalogues.md](errors/i18n-catalogues.md):

| Code | Problem |
|---|---|
| E5001 | the `[i18n]` section: an unknown key, a missing default, a non-canonical tag |
| E5002 | a locale that is not a BCP 47 tag, or that CLDR has no data for |
| E5003 | a file: bad JSON, a key twice, a value that is not a message, a folder for an unlisted locale |
| E5004 | a message that does not parse |
| E5005 | an unknown message function or option |
| E5006 | a key that the default locale does not have |
| E5007 | a placeholder that the default locale's message does not have |
| E5008 | plural forms that do not fit the locale's CLDR rules |

The build also prints the coverage of a locale that lacks some keys
(`i18n: zh-Hans has 40 of 42 keys of the default locale en-GB`).

One parser does all of this. The message parser is the runtime's
(`runtime-go/rt/i18n`). The build compiles the runtime's checker
(`rt/i18n/skyi18ncheck`) in the generated Go project and runs it, so the
build and the running program can never read a message differently. The
runtime must parse messages itself, because a tenant override arrives at
run time.

## 3. Messages

The syntax is a subset of Unicode MessageFormat 2.0, which is stable since
CLDR 47:

| Write | Means |
|---|---|
| `Hello {name}` | the argument `name`. Sky reads `{name}` as `{$name}` |
| `Hello {$name}` | the same, in MF2 form |
| `{$n :number minimumFractionDigits=2}` | a number with options |
| `{$n :integer}` | a whole number (half-even rounding) |
| `{$s :string}` | text |
| `{|name|}` | the literal text `name` |
| `\{` `\}` `\\` `\|` | a brace, a backslash, a bar |

`:number` takes `minimumFractionDigits`, `maximumFractionDigits`,
`minimumIntegerDigits`, `useGrouping` (`auto`, `always`, `never`, `min2`)
and `select` (`plural`, `ordinal`, `exact`). `:integer` takes the same less
the fraction digits. Any other function or option is error E5005.

A complex message selects a variant:

```text
.input {$count :number}
.match $count
0 {{No nights booked}}
one {{{$count} night}}
* {{{$count} nights}}
```

An exact number matches first, then the plural category, then `*`. A
`.match` must have a catch-all variant. `.local $x = {...}` names a value.
Markup (`{#b}`) and attributes (`@x`) are not supported.

A placeholder with no function formats its argument by its type:

| Argument | Shows (en-GB) |
|---|---|
| `I18n.string "Ada"` | Ada |
| `I18n.int 1234` | 1,234 |
| `I18n.decimal d` | 1,234.5 (up to three fraction digits) |
| `I18n.money m` | £1,234.50 |
| `I18n.percent d` | 12.5% for 0.125 |
| `I18n.time ms zone` | 17 Nov 2026, 14:05:09 |
| `I18n.date "2026-11-17"` | 17 Nov 2026 |
| `I18n.list [ "a", "b", "c" ]` | a, b and c |

An argument that a message names and the code does not give shows the
placeholder (`{name}`) and is logged once. It never stops the render.

## 4. Text in models

Keep a `Text` in a model, not a sentence. `I18n.text key args` is a key with
typed arguments. It is plain data, so `Codec.auto`, the Sky.Live session
store and Sky.Spa messages carry it with no codec of your own. Render it in
the reader's locale when the view runs:

```elm
notice = Just (I18n.text "booking.added" [ ( "room", I18n.string "Garden Suite" ) ])

Ui.text (I18n.render model.locale notice)
```

`I18n.verbatim s` holds text that is not a message (a name from the
database). `render` gives it back as it is.

## 5. Locales, chains and negotiation

`I18n.locale "zh-hant-hk"` gives the canonical locale "zh-Hant-HK". A lookup
goes through the locale's chain and then the default locale. The chain is
the locale, its form with the likely script when the region changes the
script, and its CLDR parents:

| Locale | Chain |
|---|---|
| zh-CN | zh-CN, zh, then the default |
| zh-HK | zh-HK, zh-Hant-HK, zh-Hant, then the default |
| en-AU | en-AU, en-001, en, then the default |

CLDR does not fall back from Traditional to Simplified Chinese, so neither
does Sky. A catalogue folder matches a chain step when both have the same
language, script and region with likely subtags filled in: the folder
"zh-Hans" serves "zh" and "zh-CN".

`I18n.negotiate supported header` picks the supported locale that best fits
an `Accept-Language` header. `I18n.direction` gives `Rtl` for Arabic,
Hebrew and the other right-to-left scripts. Use `I18n.tag` and
`I18n.direction` for the `lang` and `dir` attributes of the page.

A key with no message in any locale can only come from a key made at run
time. It shows as `⟦key⟧` outside production and as the key in production,
and it is logged once. A Sky.Spa client has no `ENV`, so it shows the key.

## 6. Overrides

A multi-tenant app can let a tenant change its wording. An override is a
value, not global state:

```elm
I18n.overrides [ { locale = enGb, key = "booking.title", message = "Your stay" } ]
    |> Result.map (\ov -> I18n.tWith ov loc "booking.title" [])
```

`overrides` checks each message and gives `Err` for one that does not parse.
For each step of the chain an override wins over the catalogue.

## 7. Formatting

`Std.I18n.Format` gives `int`, `decimal`, `percent`, `money`, `date`,
`time`, `dateTime` (styles `Short`, `Medium`, `Long`, `Full`), `list`
(`And`, `Or`, `Unit`) and `relative` (`Seconds` to `Years`, `Always` or
`Auto`). Each returns `Result Error String`.

| | en-GB | zh-Hans | de | hi |
|---|---|---|---|---|
| `decimal 1234567.891` | 1,234,567.891 | 1,234,567.891 | 1.234.567,891 | 12,34,567.891 |
| `money` GBP 1234.5 | £1,234.50 | £1,234.50 | 1.234,50 £ | £1,234.50 |
| `date Medium` | 17 Nov 2026 | 2026年11月17日 | 17.11.2026 | 17 नव॰ 2026 |
| `list And` | a, b and c | a、b和c | a, b und c | a, b और c |
| `relative Auto Days -1` | yesterday | 昨天 | gestern | कल |

Numbers round half to even, as CLDR and ICU do. A time shows its zone as a
GMT offset in the locale's form ("GMT+8"), so the text depends only on the
offset.

`list` applies the contextual rules of ICU's ListFormatter. In Spanish, "y"
becomes "e" before an /i/ sound ("España e Italia", "hija e hijo", but "agua
y hielo"), and "o" becomes "u" before an /o/ sound ("desierto u oasis", "7 u
8", "10 u 11", but "10 o 111"). In Hebrew, "ו" becomes "ו-" before an item
that does not start with a Hebrew letter ("a ו-b"). No other locale has a
contextual rule in ICU.

## 8. CLDR data and binary size

The data comes from CLDR 49.0.0 (cldr-json, pinned by SHA-256 in
`tools/cldr-gen`). The generator writes one Go file per locale with CLDR
modern coverage (423 locales) into `runtime-go/rt/i18n`. Each file holds
only what differs from its CLDR parent and has the build tag
`sky_cldr_<tag>`. Plural rules for every CLDR language are always present.

The build passes the tags of the locales in `[i18n] locales` and their CLDR
parents, and `sky_i18n`, which compiles the module's kernels. A program
that does not use the module gets no tag and links none of it. A program
that uses the module with no `[i18n]` section gets root and English only.

Formatting with a locale whose data the program does not carry is an
`Err` (domain "i18n", code "LocaleNotCompiled") whose message names the
`sky.toml` fix. It never falls back to English.

The server and a Sky.Spa client compile the same code and the same data,
so a server render and the client's hydration give the same text. Sky does
not use the browser's `Intl` API.

To update CLDR, change the version and the four SHA-256 pins in
`tools/cldr-gen/main.go`, run `go run ./tools/cldr-gen` from the repository
root, and commit the result. `go test ./tools/cldr-gen` checks that the
committed files match a regeneration byte for byte.

## 9. The pseudo-locale en-XA

List `en-XA` in `locales` to test layouts. The build makes its catalogue
from the default locale: each message accented, about 40 percent longer and
in brackets ("[Ĥéļļö {name} ·····]"). Text that shows without accents is
text that does not come from a catalogue. Do not make a folder for it.
