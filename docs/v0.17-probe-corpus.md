# v0.17 PR-1 Probe-Fixture Corpus

**Purpose:** lock the renderer parity contract for the foundation
refactor. Each fixture below is a minimal Sky program that
exercises one specific gap blocking fully-typed-e2e, sourced from
the four audits in the v0.17 deep-rethink workflow.

**Total fixtures:** 57 (50 audit-derived + 7 TCO probes per
pre-mortem lesson 1).

**Each fixture directory ships:**
```
tools/probe-fixtures/probe-<id>-<slug>/
├── sky.toml              -- minimal entry-point
├── src/Main.sky          -- the Sky program
├── golden/main.go        -- expected emitted Go (post-foundation)
├── SPEC.md               -- gap citation + MUST_* assertions
```

**SPEC.md format per fixture:**
```
# probe-<id>: <one-line summary>

## Citation
<audit ref + Compile.hs:line>

## What's broken today
<paste of current emitted Go showing the gap>

## What this fixture proves
<MUST_CONTAIN / MUST_NOT_CONTAIN list>

## Closes by
<Ship Point A/B/C/D/E + which PR>
```

## Allowlist policy (`KnownDivergence.hs`)

* Every entry MUST cite the audit gap it documents.
* Every entry MUST have a `closesByShipPoint` field naming the
  PR that empties it.
* The allowlist EMPTIES by end of Phase γ — that's the Ship Point
  B gate. PR-17's merge gate includes "allowlist size == 0".
* **Any `continue`-block byte diff** is treated as a real bug,
  NOT a formatter quirk (pre-mortem lesson 4). It does NOT go on
  the allowlist; it gets investigated.

## Probe-sweep CLI shape

```bash
scripts/probes-sweep.sh                   # runs all 57; reports pass/fail
scripts/probes-sweep.sh probe-H2          # single fixture
scripts/probes-sweep.sh --golden-update   # regenerate golden/main.go
scripts/probes-sweep.sh --tier H          # all H-tier probes
SKY_FFI_QUALIFIED=1 scripts/probes-sweep.sh --tier G  # G-tier flag toggle
```

The script is the bisection workhorse. After each PR, running it
shows which probes flipped from fail→pass (target) or pass→fail
(regression).
