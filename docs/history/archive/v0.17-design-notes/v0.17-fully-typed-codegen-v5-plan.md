## Architecture summary

Three branches (B1/B2/B3) of the type pipeline:

- **B1 — HM + annotation/inference.** Solver produces `RegionTypes`
  + per-binding `T.Annotation = T.Forall vars T.Type` + per-instance
  σ (concrete type args).
- **B2 — Sky type → Go type mapping.** Today's `solvedTypeToGo`
  is a lossy `T.Type -> String` mapper that drops parameters,
  collapses opaques, and erases TVar identity.
- **B3 — Lowering.** Should be mechanical IF B1 + B2 are sound.
  Today B3 carries enormous compensation logic
  (`goExprGoType` inverse pipeline, ~25 string-rewriting helpers,
  14 side-table IORefs) because B2 is lossy.

v5 fixes B2 (introduce typed `GoType` ADT + `MappingContext`) +
closes the 10 root-cause leaks + collapses the B3 compensation
layer.

### Phase β — Localised root cause closes (5 commits)

  Right architectural fix: land the typed pipeline (Phase γ
  C8-C12) so `solvedTypeToGo`'s TTuple arm and the literal-emit
  site change in lockstep through the new `mapSkyTypeToGo`
  mapper.  Until then, every existing emit path stays
  rt.SkyTuple2.  Reframed Phase γ commit set covers Cause H
  fully (see C12-tuple addendum below).
- **C7** feat(type): unify `safeReturnType`/With/Pure into named
  policy functions: `safeReturnTypeFull` /
  `safeReturnTypeBootstrap` / `safeReturnTypePure`. Extract

  remain. Net LOC drop ~30 (shared helper) not 700. (Closes
  Cause J.)
