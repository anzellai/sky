# v0.17 σ-Projection Registry Audit

Complete mapping of four IORef registries that contribute to the per-instance type-argument projection (σ) at the spec-emission site. This document ensures no consumer reads these registries without being catalogued, preventing soundness hazards during C12 authority flip to GoSig.

---

## 1. globalAnnotMap — IORef (Map String T.Annotation)

**Definition**  
- File: `src/Sky/Build/Compile.hs`
- Lines: 328–330
- Type: `IORef (Map.Map String T.Annotation)`
- Maps full Sky-qualified callee names to their generalised Forall annotations

**Population Sites**

| Line | Purpose |
|------|---------|
| 1396 | Write full annotation map after `Mono.reachableInstances` solves the entry module; sets globalAnnotMap once per compilation |

**Consumer Sites**

| Line | Purpose |
|------|---------|
| 1460–1462 | Read annotation in σ_sky materialisation: extract Forall quantifiers to bind against concrete instance types |
| 3747–3754 | Read and snapshot into LowerCtx.buildLowerCtx for type-directed lowering (annots parameter) |
| 3844 | Read in spec-emission loop to look up annotation Forall names; unused in σ_go build (aliased _annotMap') |
| 9218 | Read in instanceMangledName to check whether a polymorphic instance has an annotation (unused binding) |

**σ-Projection Role**  
At line 1460–1462, the Forall quantifier list extracted from globalAnnotMap drives the annotation-space σ binding: `quants = case Map.lookup skyName annotMap of Just (T.Forall vs _) -> filter (/= "any") vs; Nothing -> []`. The list of quantifier names (after stripping "any" constraints) forms the keys for the Sky-side σ_sky map. This per-instance annotation context is irreplaceable — HM alone does not preserve the Forall ordering that the solver captured, and re-deriving via `generaliseToAnnotation` produces different TVar names across pass 1 and pass 2, breaking spec consistency.

## 4. globalCsiByCallee — IORef (Map String [String])

**Definition**  
- File: `src/Sky/Build/Compile.hs`
- Lines: 363–365
- Type: `IORef (Map.Map String [String])` — maps Sky-qualified callee name to captured Forall quantifier list
- Per-callee quantifier-name list as recorded by the solver during CSI capture

**Population Sites**

| Line | Purpose |
|------|---------|
| 1433–1440 | Build and write csiByCallee from callSiteInstances + depCsiByMod; extract quantifier ordering from Solve._instance_quantifiers |

**Consumer Sites**

| Line | Purpose |
|------|---------|
| 1460 | Read in σ_sky materialisation (line 1460 uses annotMap; line 1466 reads csiByCallee to get quantifier list for the spec) |
| 3845–3866 | Read in spec-emission buildSpec lambda; look up quants for skyName to bind with concrete tys in σ_sky |

**σ-Projection Role**  
At line 3866, `quants = Map.findWithDefault [] skyName csiByCallee` retrieves the captured Forall quantifiers for each reachable instance. These quantifiers (recorded by the solver at CSI capture time) form the σ_sky binding keys. This is the authoritative "which Forall names did the solver instantiate" registry — critical because HM's re-generalisation can produce *different* TVar orderings between pass 1 and pass 2, making captured solver ordering the only reproducible source of truth. Without csiByCallee, σ-recovery at HOF call sites would fail (quants would be empty or wrong, leading to misaligned σ_sky→σ_go projection).

**Migration Feasibility**

- **globalAnnotMap → GoSig.annotation**: Straightforward — Forall quantifiers are syntactic annotation properties.
- **globalCsiByCallee → GoSig.quantifiers**: Direct — captured quantifier lists are solver outputs that GoSig should preserve.
- **_cg_funcSkyToGoTVars → GoSig.typeParams**: Requires new GoSig field for Sky→Go mapping; currently inferred from diff between annotation and codegen-time survivors.
- **globalReachableSet**: Keep separate — represents mono-instance reachability (solver + arity analysis), not per-function metadata. No GoSig analogue.

**Danger Zones for C12**

1. **Line 1460–1462 + 3866**: Quantifier extraction must preserve Forall ordering from GoSig.annotation / GoSig.quantifiers. Any reordering breaks σ_sky alignment.
2. **Line 3865–3883**: σ_go projection depends on both GoSig.typeParams (Sky→Go pairs) and concrete instance types. Missing or stale GoSig.typeParams silently produces wrong coercions.
3. **Line 9233–9264**: coerceCallArgsAt checks are the last line of σ-soundness defense. If GoSig.typeParams is incomplete, call-site args degrade to `any` silently.

**Pre-C12 Checkpoint**

Ensure every consumer read identified above has a corresponding GoSig field access before consolidation. Any uncatalogued read is a hidden σ-soundness hole.
