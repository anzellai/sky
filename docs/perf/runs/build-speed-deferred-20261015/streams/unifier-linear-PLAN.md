## Design
A. Ground stamp: Slot::Root gains g:u32; UnionFind gains epoch, in_flight. Ground iff g==epoch. fresh stamps ground for Error/Rigid/Unit/Structure with all children ground roots (record needs ext None). union stamps merged ground only if content came from a ground side. Ground-loss frame (content from non-ground side, other side ground): in_flight+=1 before union; success re-stamps merged root then decrement; Err bumps epoch then decrement. Error arm or App rename on a ground class bumps epoch. Occurs walk skips valid-ground roots only while in_flight==0.
B. unify_vars: no clones of content (:384-385); read by ref, move in Flex arms.
C. Lazy ground instances: reserve exactly the ids ty_to_var would allocate (post-order), Slot::Lazy{T,block} in the last id; content() and every raw slot read fill one level into reserved ids. Fast path unify(X, Lazy T) when X is Lazy T or X has valid stamp with identity T and in_flight==0: union roots by rank, keep X content, skip children. Ground table + instantiation plans built once per World.
Rejected: literal node sharing (content mutation via Error arm, t<id> names shift, infer.rs:2467); Remy levels; deferring occurs to read-back (moves errors).
## Invariants
I1 in_flight==0 => every child of a valid-stamped root has a valid-stamped root. I2 no Flex/FlexSuper reachable from a stamped root => skip equals full walk. I3 Lazy children ids referenced by nobody until filled; Lazy moved never cloned. I4 non-Flex class never becomes Flex; its rank/root id reach no output (names printed only for Flex/FlexSuper :2467,:2479,:2520). Flex ids and membership identical => read-back, errors, obligations, var counts identical.
